# ChatGPT Helper

This repository is my personal workspace for testing what I can do with GitHub and ChatGPT.  
It includes prompts, code snippets, drafts, and small projects I create while experimenting.

## Services
- Store and organize prompts  
- Save reusable code snippets  
- Draft website or project prototypes  
- Document learnings and experiments

## Purpose
This repo is mainly for me to explore how GitHub works and how I can use it to keep track of my work with ChatGPT.

## New: No-Code Automated Calendar Blueprint

I added a complete setup guide for building an automated task system with:
- Google Calendar sync
- SMS and push reminders
- Daily non-negotiables
- Task urgency tiers
- Completion statuses and streak tracking
- Natural-language edits

See:
- `docs/no-code-google-calendar-automation.md`
- `docs/morning-task-template.txt`

Default configuration is documented for:
- New Jersey timezone (`America/New_York`)
- 2 reminders (60 min + 10 min)
- Daily 10:00 AM summary
- Optional `Show Until Finished` rollover behavior
